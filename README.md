# Code Institute Data Analytics — Unit 2

Working repository for the Birmingham healthy life expectancy project.

## Raw data

The collected source files are in [`data/raw/`](data/raw/). They are retained in dated folders and copied without cleaning, filtering, or conversion. Start with the ONS healthy life expectancy workbook; the other files are supplementary candidates to inspect and assess.

The [source register](data/source-register.csv) records source links, periods, geography, file sizes, SHA-256 checksums, and licensing notes for the registered downloads. The Overpass railway extract and its query are dated 3 October 2026 in `data/raw/2026-10-03/`.

## Attribution

The registered public-sector sources retain their original files and source links. Follow each provider's licence and attribution statement when reusing them. The ONS boundary data requires ONS and Ordnance Survey attribution.
