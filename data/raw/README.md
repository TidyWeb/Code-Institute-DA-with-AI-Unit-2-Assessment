# Raw source files

These are the 34 collected raw files from 1 and 3 October 2026, copied in their original dated folders. No analysis transformations have been applied here. This folder includes source datasets, publisher metadata, download provenance, geography query results, and the saved Overpass query.

Use `../source-register.csv` to find the registered source URL, period, geography, checksum, and licence note for each download. The Overpass railway extract is identified in the repository README and by its saved query file.

Do not treat every file as an approved analytical input. The project starts by exploring healthy life expectancy, then assessing supplementary sources for fit and coverage.
